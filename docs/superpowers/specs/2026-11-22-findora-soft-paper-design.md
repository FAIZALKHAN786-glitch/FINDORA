# Findora — Soft Paper design

Locked direction: Warm Campus, Soft Paper variant, mostly grayscale with one clay accent (`#a8461f`).

- Surface: soft neutral paper (`#f4f4f2`) with a fine grain, paper-white cards, thin grey borders.
- Identity: custom “folded notice + pin + hidden F” mark; app name is Findora everywhere.
- Type: system stack, tight tracking on display text, calm body copy, uppercase micro-labels.
- Components: taped notice cards, dashed borders, modest rotations, pill navigation, quiet shadows.
- Colour: greys carry structure; clay carries primary actions and the few brand accents; sage/clay distinguish found/lost.
- Motion: short ease-out transitions, press feedback on controls, staggered card entrance; reduce to opacity-only for reduced motion.
- Scope: preserve all existing routes, data flow, validation, authorization and API behaviour.
